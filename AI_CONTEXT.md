# GIULIETT PÂTISSERIE

## Proyecto

Estamos rediseñando completamente la web de Giuliett Pâtisserie.

No queremos una landing genérica.

Queremos una experiencia premium inspirada en una pâtisserie boutique francesa.

La web debe sentirse como una evolución natural del brochure oficial de la marca.

No queremos reinventar la identidad.

Queremos elevarla.

---

# Filosofía

La dueña de la marca repite constantemente una idea:

"Hace falta filtrar."

La web debe eliminar todo lo innecesario.

Cada pantalla comunica una sola idea.

Cada sección responde una sola pregunta.

Menos texto.

Más imágenes.

Mucho espacio en blanco.

---

# Objetivo

Cuando un usuario entra debe entender inmediatamente:

• Quién es Giuliett.

• Qué hace.

• Qué tipo de eventos realiza.

• Cómo contratarla.

Todo lo demás es secundario.

---

# Mobile First

La mayoría de los usuarios llegan desde:

Instagram

WhatsApp

Redes sociales

Diseñar primero para celular.

Desktop es una adaptación.

---

# UX

El usuario debe poder escribir por WhatsApp en menos de 15 segundos.

Botón visible.

Navegación simple.

Mucho aire.

Nada de bloques pesados.

Nada de sliders antiguos.

Nada de cards genéricas.

---

# Animaciones

Muy sutiles.

Elegantes.

Nunca exageradas.

Priorizar fluidez.

---

# Copy

Muy emocional.

Nada de párrafos largos.

# Regla principal

Si una decisión hace que la web parezca una plantilla, descartarla.

Si una decisión hace que la web parezca una boutique premium, conservarla.
